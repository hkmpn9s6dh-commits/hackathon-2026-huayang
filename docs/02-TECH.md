# 技术路线

## 一句话

四个纯函数（周期 / 对称 / 无缝 / 分色）加一层渲染，全部跑在浏览器里，没有后端、没有模型下载、没有网络请求。

## 1. 为什么用归一化互相关测周期

第一版用的是「位移 d 时两段的平均绝对差」，取第一个显著极小。它在合成图上就错了：
小位移时相邻像素本来就相似，绝对差天然偏小，于是 16 px 会被误判成周期。

改成 **Pearson 归一化互相关**：

```
r(d) = cov(I(x), I(x+d)) / sqrt(var(I(x)) · var(I(x+d)))
```

相关函数只在真正的周期处接近 1，且不受整体亮度影响。选峰分两步：

1. 取全局最强的峰（最可靠的重复）；
2. 回到 `1/1.5` 倍以内，找第一个 `≥ 0.9 × 最强峰` 的峰 —— 那才是**基周期**，
   因为最强峰常落在周期的整数倍上（48 的图，192 处的相关也是 1.0）。

最后用抛物线插值拿到亚像素周期（实测 47.3、67.94 这类小数）。

**这道判据抓到的真 bug**：`detectPeriod` 收到的是 RGBA 图，却按单通道索引，
等于拿 R 通道去和 G 通道比。修法是入口统一 `grayOf()`。修之前 4 张合成图全错。

## 2. 对称群是工程近似，不是群论

对裁出的单元，逐项比：

- 水平镜像 / 垂直镜像
- 180° / 90° 旋转（**非方形单元不判**，返回 null —— 曾因为返回自身而让纯噪声被判成 p4）
- 滑移反射（镜像后再平移半个周期）

每项允许 ±2 px 的平移搜索，消掉「裁剪起点不在对称轴上」的偏差。得分 ≥ 0.86 记为成立，
再按组合给一个近似的 wallpaper group：`p1 / pm / pg / pmm / p2 / p4 / p4m`。

代码和文档里都写明这是**近似**：真正的群论判定要看平移子群的完整结构，
这里给的是「设计师能用的那一档」。

## 3. 接缝：先取整周期，再羽化 6%

周期测成 67.94，单元就取 68 —— 因为位图没有 0.94 个像素。
取整之后接缝本身就已经很接近内部噪声了，再做左右各 6%、上下各 6% 的边界羽化：

```
out(x) = lerp(unit(x), (unit(x) + unit(W-1-x)) / 2, t)   t: 边界 1 → 向内 0
```

判据不是「消除百分比」（那是循环论证），而是**接缝差 ÷ 内部相邻列差的中位数**，
要求 ≤ 1.5。合成图上这个比值落在 0.0–0.3。

## 4. 矢量化：颜色量化 + 像素边界追踪

1. **k-means 分色**（k=5）。初始化不用随机数，用「最暗的像素 + 依次取最远点」，
   保证同一张图两次跑结果一致（AC-08 靠这个）。
2. **像素边界追踪**：每个前景像素贡献 4 条有向边（邻居是背景时），再按起点串成闭合环。
   这比 marching squares 好写，且天然得到直角阶梯——版画的味道。
3. **Douglas–Peucker 简化**（ε=0.7）。

**这道判据抓到的真 bug**：闭合环如果先把首点补到末尾再喂给 RDP，
首尾重合会让基线长度退化为 0，整圈被压成 2 个点，然后被「至少 4 点」的过滤全部丢掉——
结果是 SVG 里一条路径都没有。修法是不补首点，直接对环做 RDP，每段各自收 `Z`。

## 5. 换色：明度归原图，色相归色板

转 LAB，把每个像素映射到色板的「暗—中—亮」三点梯度上：

```
L' = 0.82 · L_原图 + 0.18 · L_色板(插值)
a' = 0.85 · a_色板 + 0.15 · a_原图
b' = 0.85 · b_色板 + 0.15 · b_原图
```

明度以原图为主，所以结构保真度（1 − 平均 |ΔL| / 100）稳定在 0.96–0.99；
色相以色板为主，所以灰色构件换「搪瓷蓝」真的会变蓝。

第一版把 a/b 都乘 0.15，结果灰色构件换任何色板都几乎看不出变化——判据（结构保真 ≥ 0.88）
过了，但产品是坏的。这是「指标过线、体验不过线」的典型，靠 e2e 的「换色后画面确实变了」抓出来。

## 6. 取样区域

真实照片的边缘常有柱子、台阶、天光。所以：

- **测周期只看中心 64%**
- **取单元从图像中心起算**（`origin = (w/2 − px/2, h/2 − py/2)`）
- 网格线按 `origin % 周期` 的相位铺满全图，取样框画在 origin 处

这三条把「一张有环境的照片」和「一张被裁干净的样板」区分开了。

## 7. 代码结构

```
src/core/    纯函数，无 DOM。Node 里可直接 import（node 22 原生剥类型）
  image.ts     Gray / RGB 与环绕取样、平铺
  period.ts    归一化互相关测周期
  symmetry.ts  对称群近似判定
  seamless.ts  取整 + 羽化 + 接缝比
  vectorize.ts k-means + 边界追踪 + RDP + SVG
  palette.ts   LAB 转换 + 六套工业色板 + 换色
src/main.ts  渲染与交互（canvas 2D，无框架）
scripts/     synth（合成真值）/ verify（86 条断言）/ e2e（26 条浏览器断言）
```
