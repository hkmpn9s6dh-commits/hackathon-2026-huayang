# 尺子 — 这件东西该长什么样

> 闸 A 的第二件产物。清台的规矩：宿主规范 + 至少 5 件可参照的作品，每件写「学哪一点」，
> 不写「像它」。学的是方法，不是壳。

## 一、宿主规范

本作的宿主是**浏览器**，不是某个平台。所以规范只有两条硬的：

1. **WCAG 2.2 AA**：正文对比度 ≥ 4.5:1、所有控件可 Tab 到达、焦点环可见、`prefers-reduced-motion` 时不放扫描动画。
2. **可离线**：不发任何外部请求。图片不上传，字体用系统栈，图标用 SVG 内联。
   评审打开 Demo 时，断网也应该能用。
3. 补充一条自定的：**每个读数必须带单位**。周期写 `px`、置信写百分数、接缝写倍数。
   一个没有单位的数字，在制造业里等于没说。

## 二、六把尺子

首届赛事没有往届得奖作。所以尺子从「同类工具」和「同类档案」里取，取的是它们各自解决得最好的那一点。

| # | 尺子 | 学哪一点 |
|---|---|---|
| 1 | **Adobe Capture**（拍一张照片，取出形状 / 颜色 / 图案） | **一次点击的闭环**：用户不需要知道背后是边缘检测还是聚类，点一下就该拿到能用的东西。它从不要求用户先画框、先选区。 |
| 2 | **Patterned.ai**（生成图案的商业工具） | **参数的粒度**：可控的东西要少而准——尺度、密度、配色、平铺方式。参数一多，用户就放弃了。 |
| 3 | **V&A 的纹样档案**（维多利亚与艾尔伯特博物馆的图案收藏在线） | **档案的呈现**：每张图配编号、年代、材质、出处。一张纸之所以值钱，是因为它可被引用。→ 这里的对应物是「规格书」。 |
| 4 | **Cooper Hewitt 的壁纸收藏** | **把一张纸讲成一个物件**：它不是「图案素材」，它是「某年某厂印的、贴在某个房间的墙纸」。→ 这里落到页面上的「构件名 + 编号 + 一句来源」。 |
| 5 | **工业视觉检测软件的检验界面**（这一类的通行做法：大字号读数 + 单位 + 判定戳） | **读数的层级**：值大、标签小、合格与否用一枚戳。看的人先看结论，再看细节。 |
| 6 | **Figma 右侧检查器** | **分组的克制**：属性按「几何 / 外观 / 导出」分三组，不折叠、不嵌套、不搞标签页。工具类界面的高级感来自克制，不来自装饰。 |

## 三、记忆点（只有一个）

**照片上那张青色的周期网。**

它同时干了三件事：证明「我看懂了这张照片的重复结构」、给出「一个单元有多大」、
暗示「接下来可以把它拆下来」。一次呼吸之内说完，不需要动画解释。

配套的视觉语法：
- 网格线 = 青色（`#08746e`），带 5 px 的淡青光晕（真实 1 px 细线在混凝土上不可见）
- 取样单元 = 四角 L 形括号（白描边打底 + 深青），像检验台上的取景框
- 对称轴 = 锈红虚线（`#8c3a2b`），只在检出镜像时才出现

## 四、主屏规格

| 项 | 值 |
|---|---|
| 画布 | 三栏：左 208 px 构件库 / 中自适应画布 / 右 288 px 检验单 |
| 纸色 | `#f3efe6`（底）/ `#faf8f2`（面板）/ `#f7f4ec`（画布） |
| 墨色 | `#1b1a17`（主）/ `#5d574e`（次）/ `#8c857a`（弱） |
| 强调 | 青 `#0f9b93`（检测）/ 锈 `#8c3a2b`（对称轴、品牌点） |
| 标题 | 宋体（`Songti SC` 栈），字距 0.14em |
| 读数 | 等宽（`ui-monospace` 栈），`tabular-nums` |
| 网格 | 12 栏不用；栏宽由三栏硬分，靠 1 px 实线分隔 |
| 圆角 | 全部 0。工业图纸不圆角。 |
| 阴影 | 只给画布一层：`0 14px 30px -22px` |

## 五、已知的取舍

- **不做深色模式**：纸色是这个作品的语义（图纸、样册、检验单）。深色会让「纸」的隐喻失效。
- **不用 web 字体**：离线优先。宋体走系统栈，Windows 上落到 SimSun，Mac 上落到 Songti SC。
  代价是不同机器字形会有差异，接受。
- **单元放大用最近邻**：68×71 的单元放到 500 px 宽，最近邻会出锯齿。
  这是诚实的——它提醒用户「这张照片只有这么多像素」，而不是用插值假装清晰。
